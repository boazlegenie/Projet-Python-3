# Jeu de Course 2D - Projet POO 2026

Ce projet est un jeu de course de voitures en 2D inspiré de Trackmania et Mario Kart, développé en Python avec l'architecture MVC.

## Installation

1. Assurez-vous d'avoir Python installé sur votre ordinateur.
2. Ouvrez un terminal dans le dossier du jeu.
3. Installez les dépendances requises (Pygame) en exécutant la commande suivante :
   ```bash
   pip install -r requirements.txt


## Répartition des tâches Groupe CIMES
   Membre 1 (Assane) (Physique des véhicules): Gérer la dynamique des voitures, incluant l'accélération, le freinage, le braquage et la logique de dérapage réaliste.
   
   Membre 2 (Boaz) (Carte et environnement): Implémenter les terrains (route, herbe, terre, glace, vide) avec leurs effets sur l'adhérence, et programmer les blocs de passage, lignes d'arrivée et boosts.
      
   Membre 3 (Xu) (Interface et Contrôles): Développer le menu de navigation, l'affichage global de la vue, et la configuration du contrôleur pour gérer deux joueurs simultanément sur un seul clavier.
